# 🌐 Lab 02 - Enterprise Campus Network

## 📖 Description

This project simulates an enterprise campus network built in Cisco Packet Tracer.

The network was designed using multiple VLANs, inter-VLAN routing, wireless access, DHCP services, servers, and network segmentation to provide connectivity for administrative staff, students, guests, and enterprise services.

---

## 🎯 Objectives

- Design a medium-size enterprise network.
- Implement VLAN segmentation.
- Configure Router-on-a-Stick.
- Configure DHCP services.
- Connect wired and wireless devices.
- Simulate enterprise network infrastructure.
- Practice network documentation.
