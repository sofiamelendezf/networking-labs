# 🌐 Lab 01 - Enterprise Network Design

## 📖 Description

This lab consists of the design and implementation of a small enterprise network using Cisco Packet Tracer.

The objective was to build a segmented network using VLANs while providing connectivity between wired and wireless devices through inter-VLAN routing.

---

## 🎯 Objectives

- Design an enterprise network topology.
- Configure VLAN segmentation.
- Configure inter-VLAN routing using Router-on-a-Stick.
- Configure DHCP services.
- Connect wired and wireless clients.
- Practice enterprise network design concepts.

---

## 🛠 Technologies

- Cisco Packet Tracer

- Access Point
- DHCP

- Inter-VLAN Routing

---

## 🌐 Network Overview

The topology includes:

- Router 2911
- Core Switch
- Access Switch
- Wireless Access Point
- Server
- PCs
- Wireless laptops
- Printer

Network segmentation was implemented using the following VLANs:

| VLAN | Purpose |
|------|---------|
| VLAN 10 | Administration |
| VLAN 20 | Students |
| VLAN 30 | Guest Wi-Fi |
| VLAN 40 | Servers |
