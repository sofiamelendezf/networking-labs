# 🦈 Wireshark Labs

## 📖 Description

This repository contains my Wireshark labs completed while studying networking and cybersecurity.

The purpose of these labs is to analyze real network traffic, identify protocols, understand how communication works between devices, and strengthen my packet analysis skills.

---

## 🎯 Objective

Develop practical experience using Wireshark to capture, inspect, and troubleshoot network traffic while improving my understanding of network protocols.

---

## 🛠 Tools

- Wireshark
- Windows
- Linux (future labs)
- Virtual Machines (future labs)

---

## 📂 Repository Structure

Each lab includes:

- 📄 README explaining the objective
- 📦 Packet capture (.pcapng)
- 📸 Screenshots
- 📝 Notes and observations
- ✅ Key findings
